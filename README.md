# HIV low-level viremia
This repository includes code and select data to reproduce the analysis in the manuscript "Quantifying uncertainty in HIV-1 transmission risk from persons with low-level viremia." These data were collects as part of the population-based Rakai Community Cohort Study (RCCS) between 1994 and 2023. Interested parties can contact the Rakai Health Sciences Program (datarequests@rhsp.org) to request managed access to cohort data. 

This analysis includes four main components: 

1. `scripts/run_do_linkage.sh`: This script uses p24 and gp41 alignments as well as data on partnership intervals to 1) calibrate genetic distance cutoffs based on intra- and inter-individual distances (`scripts/couples_genetic_linkage.py`), 2) identify which couples in the included coupling intervals contributed by serodifferent couples are genetically linked (`scripts/couples_genetic_linkage.py`), 3) identify nearest neighbors of individuals in serodifferent couples for phylogenetic analysis (`scripts/couples_genetic_linkage.py`), 4) Build p24 and gp41 trees using data from individuals in serodifferent couples and their nearest neighbors by genetic distance, 5) Identify couples linked by phylogenetic topology (`scripts/couples_phylo_linkage.py `). **Due to privacy concerns related to HIV transmission among RCCS participants we are not able to share the genetic data coupled with data on self-reported couples. As such, it is not possible to reproduce this analysis based on data that are able to be shared publicly. The code is provided for methods transparency.**

2. `scripts/calc_prev.py`: This script uses viral load data between RCCS survey round 16 (2013 - 2015) and round 20 (2021-2023) to first generate a point-estimate for the prevalence of HIV <200 copies/mL, HIV 200-1,000 copies/mL, and HIV >1,000 copies/mL among all survey participants accounting for missing HIV viral load and serostatus data. Further, it uses a Bayesian mixed-effects model (implemented in CmdStan, `stan/calc_prev.stan`) to estimate the prevalence of viral loads between 200-1,000 among all participants and among those with HIV and viral load >200 adjusted for missing data as well as repeated observations between individuals. The data used in this analysis are shared in `data/RCCSdata_R016_R020_vl.tsv`. This analysis can be reproduced with the command:
	```
	python3 -u scripts/calc_prev.py \
		--dat data/RCCSdata_R016_R020_vl.tsv \
		&> output/RCCSdata_R016_R020_est_prev_llv.log
	```

3. `scripts/run_vl_trans_models.sh`: This script houses most of the viral load x transmission rate inference. It takes as input three files, 1) `data/not_shared/prox4.0_donor-noacute_recipient-exclusivelymonogamous_RCCSdata_R001_R019_all_copies_merged_d.tsv`: all cohort viral load data since 1994, 2) `data/not_shared/prox4.0_donor-noacute_recipient-exclusivelymonogamous_RCCSdata_R001_R019_all_copies_merged_p_d.tsv `: data on periods of monogamous, serodifferent partnership between cohabitating couples, and 3) `output/couples_linkage_sum_simple.tsv`: a summary of which couples are genetically linked based on the results of the `scripts/run_do_linkage.sh` analyses. This analysis uses the `scripts/full_bayesian_model.py` script to drive the analyses which are implement in CmdStan using the `stan/vl_trans.stan` and `stan/vl_trans_pred.stan` files. Select posterior draws from this analysis are available in the `output/*/select_draws.tsv` files. **Due to privacy concerns related to HIV transmission among RCCS participants we are not able to share data on self-reported couples. As such, it is not possible to reproduce this analysis based on data that are able to be shared publicly. The code is provided for methods transparency. Further, we provide mock data files (`data/MOCK_copies.tsv`, `data/MOCK_periods.tsv`, `data/MOCK_linkage_sum_simple.tsv`) that have been generated by obscuring the true data and can be used to re-run the inference framework. E.g.,**
	```
	bash scripts/run_vl_trans_models.sh \
		data/MOCK_copies.tsv \
		data/MOCK_periods.tsv \
		data/MOCK_linkage_sum_simple.tsv
	```
Please note that divergent transitions observed when fitting the model to the mock data are unique to the mock data and are not recapitulated when running on the true data. 

4. `scripts/run_simulate_trajectories.sh`: This script uses paired viral load measurements to estimate the rate of rebound among individuals with LLV then simulates viral load trajectories conditional on estimated rates, and estimates transmission risk using these simulated trajectories and the output of the `scripts/run_vl_trans_models.sh` analysis. Finally, additional trajectories are simulated under fixed rebound rates and transmission risk estimated in an analogous manner. These analyses depend on the `scripts/forward_simulate_fit_inference.py ` file which houses the simulation architecture as well as various config and params files in the `config` directory. This analysis can be reproduced with the command:
	```
	bash scripts/run_simulate_trajectories.sh
	```

5. `scripts/run_plot_main_text_figures.sh`, `scripts/run_plot_plot_supp_text_figures.sh`: These scripts take the data and output of the previous analyses and generate manuscript figures. **Please note that due to privacy concerns related to HIV transmission among RCCS participants we are not able to share all of the data needed to reproduce these figures publicly. The code is provided for methods transparency.** The output figures are all provided in `figures/pdf/*` and `figures/eps/*`. 

6. `scripts/calc_stats.py`: This script takes the data and output of the previous analyses to reproduce various statistics used in the manuscript. **PLease note that due to privacy concerns related to HIV transmission among RCCS participants we are not able to share all of the data needed to reproduce these statistics. The code is provided for methods transparency.** The output statistics are provided in `output/statistics.csv`

Additionally, we provide a `scripts/run_all.sh` driver script that demonstrates how the entire analysis pipeline was run.
